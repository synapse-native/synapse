## Por qué se conservó este borrador

Se preserva como referencia histórica para:

1. **Trazabilidad:** Permite ver cómo evolucionó la documentación.
2. **Investigación:** Útil para entender decisiones tomadas en versiones anteriores.
3. **Respaldo:** En caso de que se necesite recuperar contenido que se eliminó en la migración.
