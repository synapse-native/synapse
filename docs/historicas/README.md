## Por qué existe esta carpeta

Esta carpeta preserva documentación obsoleta por las siguientes razones:

1. **Trazabilidad** — Permite rastrear la evolución del proyecto
2. **Investigación** — Útil para entender decisiones arquitectónicas pasadas
3. **Respaldo** — En caso de que se necesite recuperar contenido eliminado
