## Problema

Run `45185835609`, job `137731068175` (macos-latest):

```
runtime/core/detect_hardware.c:61:26: error: '_SC_AVPHYS_PAGES' undeclared (first use in this function)
```

`_SC_AVPHYS_PAGES` es una extensión de `sysconf` **solo de Linux**.

## Cambios

- `_syn_memoria_libre` gana `#elif defined(__APPLE__)` que consulta el VM del
  kernel: `host_page_size` + `host_statistics64` y suma
  `free + inactive + speculative` por tamaño de página.
- `mach/mach.h` se incluye solo bajo `__APPLE__`; el `#else` POSIX restante
  devuelve 0 (no se fabrica el dato). Las ramas Windows y Linux no cambian.

## Corrección de oráculo declarada

`tests/auditoria/test_r317_detect_hardware_macos.py` afirmaba que macOS expone
`_SC_AVPHYS_PAGES`. Se sustituyó esa aserción por "existe rama macOS"; la
implementación concreta la cubre `test_r318_detect_hardware_macos_mem.py`.
