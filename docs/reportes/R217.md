## Objetivo

Cerrar la deuda r217 de R207: reutilizar `opensyn/explorer_det.syn` y
`opensyn/architect_det.syn` en `opensyn/pipeline_multiagente.syn` y retirar las
copias locales de las fases deterministas.

## Cambios

- `opensyn/pipeline_multiagente.syn`: importa `opensyn.explorer_det` y
  `opensyn.architect_det`; elimina las estructuras locales `ArchivoRelevante`,
  `NodoAfectado`, `ContratoCritico`, `Ciclo` y `MetricasImpacto`, y las funciones
  locales `explorar_contexto`, `analizar_impacto_completo` y `archivo_de_id`.
  La fase Architect consume `AnalisisImpacto` y copia sus métricas aplanadas a
  `ContextoPipeline`.
- `opensyn/architect_det.syn`: reemplaza `a_texto(nodo.num_dependientes)` por
  `entero_a_texto(...)` para evitar la colisión con `std.json.a_texto` cuando el
  pipeline importa ambos módulos (H-R207-2).
- `docs/plan_ME_r217_integracion_determinista.md`,
  `docs/alineacion/r217_integracion_determinista.md`,
  `docs/verificacion_ME_r217_integracion_determinista.md` y evidencia
  `auditoria/evidencia/c5e70770a1514592.json`.

## Desviaciones

- El `r217_loop_integracion` del plan maestro cablea `validation_loop` al loop
  vivo de `principal.syn`; este ME cierra la deuda homónima de R207. Se usa el
  id `r217_integracion_determinista` para no colisionar con el ME del plan
  maestro.
- `cargar_grafo_proyecto` sigue devolviendo un grafo vacío cuando no hay grafo
  persistido; el cableado a un grafo real corresponde al ME de grafo/pipeline.
- `explorer_det` y `architect_det` conservan helpers homónimos
  `archivo_de_nodo`/`elemento_texto`; son equivalentes y el enlace modular usa
  `--allow-multiple-definition`. No se renombraron para no ampliar este ME.
- No se modificaron tests existentes.
- No se tocaron `docs/gobernancia/GUIA_DE_GOBERNANZA.md` ni los artefactos no
  rastreados `nucleo/embedded_libs.h` (artefacto eliminado), `nucleo/lsp_v3.c.bak` (artefacto eliminado) y
  `nucleo/lsp_v3.c.new` (artefacto eliminado).
