# R73 — F14-2: Stack overflow en validate_formal_proof.exe

## Hallazgo
`validate_formal_proof.exe` presentaba stack overflow (exit code `0xC00000FD`) al final de la suite de 95 tests.

## Causa raíz
Stack default de Windows (1MB) insuficiente para la suite con buffers locales grandes (`PB_MAX_EXPR_LEN` = 64KB, `PB_MAX_FILE_LEN` = 64KB) en tests estáticos.

## Fix
Link con `-Wl,--stack,8388608` (8MB).

## Cambios
- `tests/conftest.py` `_RT_BINARIOS_EXTRA`: añadido `validate_formal_proof` con flag de stack.
- `tests/conftest.py` `_RT_OBJ_DEFS`: añadido `proof_bridge.o`.
- Loop de compilación: soporta 4ª tupla `extra_flags`.

## Validación
- Build automático rc=0.
- Ejecución 95/95 PASS.

- **Regla 9** (no inventar — flag estándar de GCC/MinGW para stack).
