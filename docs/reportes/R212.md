## Objetivo

Sacar `opensyn/memoria_persistente_cifrada.syn` del baseline de compilación:
reescribir el módulo sobre las primitivas reales del runtime (XSalsa20-Poly1305,
SHA-256, pool de memoria) conservando el modelo de tres capas del agente, y
demostrar escritura/lectura cifrada persistente sin fuga de texto en claro.

## Desviaciones

- H-R212-1: Argon2id no existe en el runtime; `derivar_clave` usa SHA-256
  iterado (20000 rondas) con sal de hardware. Resolución: implementar Argon2id
  en un ME posterior; el módulo queda aislado tras `derivar_clave`.
- H-R212-2: no hay API SQLite expuesta a Synapse; la capa Evolución usa un
  almacén cifrado plano con una entrada cifrada por línea. Resolución: binding
  SQLite cifrado cuando el runtime lo exponga.
- H-R212-3: S1 no soporta variables globales mutables; la API usa
  `MemoriaCifrada` explícito y el llamador reasigna el estado devuelto.
- El E2E destapó una corrupción de pool en `tokenizar`:
  `tokens.agregar(minusculas(actual))` duplicaba la expresión en el constructor
  de la estructura y `minusculas` (función pura) libera su parámetro, causando
  triple free del mismo bloque. Se corrigió con
  `let token = minusculas(_syn_strcpy(actual))` antes de `agregar`.
- El driver del E2E es idempotente: si el proyecto ya existe no vuelve a
  guardar, de modo que la prueba de persistencia no duplica entradas.
- No se modificaron tests existentes; el test E2E es nuevo de este ME.
- No se tocaron `docs/gobernancia/GUIA_DE_GOBERNANZA.md` ni los artefactos no
  rastreados `nucleo/embedded_libs.h` (artefacto eliminado), `nucleo/lsp_v3.c.bak` (artefacto eliminado) y
  `nucleo/lsp_v3.c.new` (artefacto eliminado).

## Lecciones

- El E2E de comportamiento es necesario: `--check` y los tests estructurales no
  detectan corrupciones de pool en tiempo de ejecución (el programa compilaba y
  devolvía basura).
- En S1 las funciones puras liberan sus parámetros `texto`; pasar el resultado
  de otra función pura como argumento duplica la expresión en el constructor y
  provoca doble/triple free. Duplicar con `_syn_strcpy` antes de transformar.
- `_syn_a_texto_decimal` usa `%g`: la representación de `0.9` no es `0.900000`.
- Un driver E2E que escribe y luego lee debe ser idempotente para que la
  persistencia se pueda probar en más de una ejecución.
