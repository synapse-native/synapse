DETALLES TECNICOS:
  1. **JSON plano v2 (syquex/syq_json.syn:131-166):** `syq_json_emitir(raiz)` recorre el SemNodo[] de salida y emite `[{t,l,c,vi,izq,der,herm,extra,txt1,txt2}]` a stdout con versión `"syquex_flat":"2"`. txt1 = span primario (nombre/literal); txt2 = span slot2 (tipo de retorno/parámetro/campo/alias), leído vía `trad_s2p/s2h/s2l` (Manual 3 §11.2). Los tipos de nodo provienen de `trad_nodo_tipo/tamano/columna/izq/der/herm` (ABI R85).

  2. **CLI (syquex/syq_main.syn:58-83):** `principal()` recibe `<fuente.syq>`, lee el archivo via `fopen/asm` (1MB buffer estático), ejecuta `sq_programa()` → `traducir_programa()` → `syq_json_emitir()`. Códigos de salida: 0 OK, -10 sin argv, -11 fuente ilegible, negativo = código del traductor.

  3. **Build (scripts/build_syquex_frontend.py):** concatena 9 módulos + syq_main, dedup `constante T_*/NODO_*` (primera gana), compila via `main.py` con timeout 900s, verifica timestamp anti-stale.

   4. **Puente Python (compilador/puente_canonico.py:40-112):** `NOMBRE_NODO` (28 tipos) mapea `tipo` → AST; `CODIGO_OPS` (vi 100-402) mapea operadores sin lexema (fallback desugar para-rango, ej. vi=201 → "<"). `NO_SOPORTADOS` 54/55/56/57 → `PuenteError` fail-fast (H-R90-1). `plano_a_programa(flat)` reconstruye `Programa` con hijos por índice, hermanos por slot6, tipos por slot2. **H-R90-5 lowering**: `_build_contexto()` escanea ESTRUCTURA/FUNCION/LET para construir `_struct_metodos` (nombre decorado "Struct_method") y `_var_tipo` (tipo explícito o inferido del constructor); `_tipo_objeto()` resuelve el tipo del receptor; `ACCESO_CAMPO` con hijo_der → `LlamadaFuncion("Struct_method", [self]+args)` con self inyectado.

  5. **Asignación indexada (H-R90-2):** `a[i] = expr` produce NODO_INDICE(29)+NODO_ASIGNACION(7) pero `plano_a_programa` no tiene una clase `AsignacionIndexada` en ast_nodes → `PuenteError` (cableado backend pendiente).

HALLAZGOS REGISTRADOS:
  - H-R90-1 (Pendiente, Fase 24): INTENTO(54) multi-sentencia, LISTA_LIT(55), MAPA_LIT(56), PARA_EN(57) no soportados por el puente — fail-fast con PuenteError (sin pérdida silenciosa). El codegen S1 para TRY/ATRAPAR, LISTA y MAPA está en Fases 24-25.
  - H-R90-2 (Pendiente, Fase 24): asignación indexada `a[i] = x` no tiene representación en el AST tipado S1 actual → PuenteError.
  - H-R90-3 (RESUELTO, commit `923ee81`): `externo estructura Vec3` (vi=1) mapeado a `DeclaracionExterna(tipo_retorno="__extern_struct")` — marker sentinela evita tocar el constructor de `DeclaracionExterna` y permite al codegen (`visitar_externa`, `emit_declarations.py`) emitir `extern struct {nombre};`; `canonical.py` renderiza `externo estructura X`; `semantic_checker.py` registra el nombre en `_estructuras` (forward declaration) en vez de en la tabla de símbolos.
  - H-R90-4 (RESUELTO corte 3, f5d6d28): literales de cadena TRUNCADOS — el lexer Syquex almacena el valor ya decodificado y SIN comillas, pero parse_primario_sq volvía a recortar (+1/-2) → "cero" se traducía como "er". Destapado por el e2e (salida del binario). Fix en expr.syn: span = valor completo del token. Los tests previos no lo detectaban porque ningún assert cubría textos de CADENA_LIT.
   - H-R90-5 (RESUELTO, commit `d64364a`): lowering de call-sites OOP — `obj.metodo(a)` deja los args en hijo_der del ACCESO_CAMPO; el puente resuelve el tipo del receptor (`_tipo_objeto`), mapea `metodo` → `Struct_metodo` (nombre decorado del NODO_FUNCION) e inyecta `self` como primer argumento → `LlamadaFuncion("Struct_metodo", [obj]+args)`. Pre-pase en el puente Python (Opción B) construye: `_struct_nombres` (de ESTRUCTURA), `_struct_metodos` (de FUNCION con nombre "Struct_method"), `_var_tipo` (de LET/declaración con tipo explícito o inferido del constructor `Struct(expr)`). `Punto(x)` (constructor call) se deja pasar como `LlamadaFuncion(nombre="Punto")` y el codegen S1 la resuelve como compound literal C (`emit_expressions.py:439-444`). No se añadió clase AST nueva: el lowering reutiliza `LlamadaFuncion` existente.
  - H-R90-6 (RESUETO, commit `f758556`): `coincidir` sobre primitivos — `visitar_coincidir` detecta tipos primitivos (PRIMITIVOS) y usa `switch(valor)` + `case literal` en vez de `switch(valor.tag)` + `case TAG_*`; el e2e deja de usar el workaround `si/sino` equivalente. También se corrigió bug slot CASO: el traductor (`traductor.syn:547-554`) almacena el cuerpo del CASO en `hijo_izq` (índice 4) no en `hijo_der`; el puente ahora lee índice 4.
  - H-R86-1 (Verificado R90): sin duplicación str_eq; el dedup Python en el build harness maneja T_*/NODO_*. El dedup en unity build C completo (`_seen_sym` en pipeline.py) queda como mejora futura.
  - NOTA de convención parser (f5d6d28): parse_postfix_sq ahora crea NODO_LLAMADA cuando la base es identificador simple (args en hijo_der — paridad con el frontend nativo Synapse y su puente); antes los args colgaban del IDENTIFICADOR, forma invisible para ambos backends.

RIESGOS IDENTIFICADOS:
  - El frontend SyQuex (`syq_frontend.exe`) genera C intermedio via S1, pero no usa el backend nativo (`nucleo/*.syn`). La paridad con el toolchain nativo se valida por separado (criterio R10/R13).
  - El buffer de archivo de 1MB (`sm_leer_archivo`) es estático; archivos >1MB se truncan silenciosamente (limite documentado).
  - `CODIGO_OPS` solo cubre operadores binarias/unarias del desugar para-rango; operadores de comparación complejos o personalizados requerirían ampliación del mapa.
