# R74 — F15-1: QC_MAX_QUBITS inconsistente entre Synapse y runtime C

## Hallazgo
`std/quantum.syn` definía `constante QC_MAX_QUBITS = 8`, pero el runtime C (`nucleo/quantum_runtime.h`) ya definía `#define QC_MAX_QUBITS 9` y el código de Shor 9-qubit QEC (`std/quantum_err_corr.syn`) requiere 9 qubits.

## Fix
Cambiar `constante QC_MAX_QUBITS = 8` a `constante QC_MAX_QUBITS = 9` en `std/quantum.syn`.

## Validación
- `validate_quantum_err_corr` 30/30 PASS.
- `validate_quantum_runtime` 93/94 PASS (1 fallo preexistente no relacionado).

- **Regla 1** (los manuales son la ley — el runtime ya soportaba 9).
- **Regla 11** (cero deuda — resuelta en este commit).
