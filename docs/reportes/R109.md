## Entregables

### opensyn/transpiler.py
- Wrapper Python del transpiler definido en `transpiler.syq`
- Mapeo completo: tipos (int→entero, float→decimal, str→texto, bool→booleano)
- Mapeo keywords: def→funcion, class→estructura, if→si, while→mientras, for→para
- Mapeo builtins: print→escribir_linea, len→longitud, append→agregar, range→rango
- Soporte para `for...in` → `para...en` (regex combinado)
- Manejo de `Optional<T>`, `list<T>`, `dict<K,V>` en tipos

### --transpile flag en CLI
- **Uso:** `python cli.py --transpile input.py [-o output.syq]`
- Si no se especifica `-o`, genera `<nombre>.syq` junto al `.py` original
- Salida a stdout si no hay `-o`

### Bugfixes
- **Unicode →:** Carácter `→` reemplazado por `->` en mensajes (compatibilidad Windows cp1252)
- **`for...in`:** Regex combinado para manejar `for x in range()` correctamente
- **`range` → `rango`:** Añadido a la tabla de builtins

## Uso

```bash
# Transpilar archivo Python a Syquex
python cli.py --transpile mi_codigo.py

# Transpilar con salida personalizada
python cli.py --transpile mi_codigo.py -o output.syq

# Transpilar y compilar en un paso (futuro)
python cli.py --transpile mi_codigo.py && python cli.py output.syq
```
