## Lecciones

- El criterio de "código muerto" necesita un **alcance** explícito: contar
  apariciones en todo el repo desde el filesystem mezcla archivos de trabajo no
  versionados y módulos que no se enlazan; la alcanzabilidad desde la entrada
  del build es el criterio verificable.
- Podar una función puede dejar huérfanas sus auxiliares privadas: el barrido
  debe ser iterativo hasta punto fijo (el ratchet lo detectó en la segunda
  pasada).
