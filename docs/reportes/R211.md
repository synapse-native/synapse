Dejar `opensyn/architect_det.syn` compilable y verificable E2E: análisis de
impacto directo/indirecto con DFS invertido, contratos críticos, detección de
ciclos y métricas sobre `GrafoProyecto`, sin LLM.

## Desviaciones

- El plan maestro cita Manual 32 §4.4/§4.6, pero `docs/manuales/MANUAL 32.md`
  no existe con ese nombre: el archivo real es
  `MANUAL  FASE 32 AGENTE DE CODIFICACIÓN.md` (doble espacio) y el índice de
  manuales no lo reconoce. El gate de alineación se ancla en Manual 6 §1.1
  (sección mapeada) y Manual 2 §5.1; Manual 32 §4.4/§4.6 queda como referencia
  funcional.
- `detectar_ciclo_tarjan` detecta un ciclo que contiene el nodo de inicio
  mediante DFS determinista; no construye todos los SCC del grafo.
- H-R207-1: el codegen emite campos ADT anidados como puntero y el constructor
  con valor no enlaza. Para evitar un puntero colgante a una variable local,
  `AnalisisImpacto` aplana las métricas en campos enteros
  (`metricas_total_afectados`, `metricas_profundidad_maxima`,
  `metricas_contratos_criticos`, `metricas_ciclos_potenciales`);
  `MetricasImpacto` se conserva como tipo público.
- S1 no soporta `continuar`; los bucles usan condiciones anidadas. La
  indexación directa de `Lista<texto>` infería `int`, por eso se agregó
  `elemento_texto` con contrato.
- No se modificaron tests existentes; el oráculo E2E es nuevo.
- No se tocaron `docs/gobernancia/GUIA_DE_GOBERNANZA.md` ni los artefactos no
  rastreados `nucleo/embedded_libs.h` (artefacto eliminado), `nucleo/lsp_v3.c.bak` (artefacto eliminado) y
  `nucleo/lsp_v3.c.new` (artefacto eliminado).

## Lecciones

- El codegen de structs anidados (H-R207-1) emite el campo como puntero; pasar
  `&local` compila pero deja un puntero colgante. Aplanar el struct es la
  solución segura mientras el codegen no se repare.
- Un campo ADT anidado puede fallar recién en el enlace del driver, no en
  `--check`; el oráculo E2E es necesario para detectarlo.
- `NodoAfectado.tipo_relacion` debe describir la relación de impacto
  (`dependiente`), no el tipo de arista del grafo (`llamada`).
- El gate de lectura previa se satisface con `alineacion.py --leer --me` además
  de `registrar_lectura.py`; el pre-commit exige el sello `.antes.json`.
