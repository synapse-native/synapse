# R114 — Fase 26: Fix SQLite Linker — Pipeline End-to-End Funcional

**Fecha:** 2026-08-26
**Rama:** feature/fase2-nativa-hm
**Commit código:** `5bc0dff`

## Problema

El pipeline `.py → .syq → .c → .exe` compilaba pero el linker fallaba con:
```
undefined reference to `sqlite3_errmsg'
undefined reference to `sqlite3_changes'
undefined reference to `sqlite3_column_int64'
...
```

**Causa:** `vendor/sqlite3/sqlite3.c` no estaba en `_RT_FUENTES` en `pipeline.py`.

## Solución

Añadido `vendor/sqlite3/sqlite3.c` a `_RT_FUENTES`:
```python
_RT_FUENTES = (
    "synapse_rt.c",
) + _RT_CORE_FUENTES + (
    "axon/tweetnacl.c",
    "vendor/sqlite3/sqlite3.c",  # SQLite bundled (lib/db.syq)
)
```
