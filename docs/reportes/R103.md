## Implementación

### syquex/ffi_marshaling.syq
API de alto nivel para marshaling automático de tipos Syquex a C:
- `_texto_a_c_string(texto, arena)` — zero-copy: añade \0 en arena
- `_entero_a_i64(valor)` — conversión directa entero → int64_t
- `_decimal_a_f64(valor)` — conversión directa decimal → double
- `_booleano_a_int(valor)` — conversión booleano → int (0/1)
- `_lista_a_slice(ptr, tipo)` — acceso a datos de lista
- `_registrar_callback_c(ptr_funcion, ptr_dato, es_debil)` — lifecycle §7.3
- `_desregistrar_callback_c(id)` — des-registro
- `_invocar_callback_c(id)` — invocación segura

### runtime/core/ffi_marshaling.c
Implementación C completa:
- **§7.2.1:** `ffi_texto_a_c_string()` — zero-copy, añade \0 en arena
- **§7.2.2:** Conversión de tipos primitivos (entero, decimal, booleano)
- **§7.2.3:** Conversión de colecciones (lista→slice, mapa→handle)
- **§7.3:** Lifecycle management — registro estático de FFI_MAX_CALLBACKS callbacks con soporte weak refs
