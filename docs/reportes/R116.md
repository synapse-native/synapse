# R116 — Fix Conflicting Types for 'main' en Codegen

**Fecha:** 2026-08-26
**Rama:** feature/fase2-nativa-hm
**Commit código:** `c4984ea`

## Problema

El compilador generaba DOS funciones `main` en el mismo archivo C:
1. `int64_t main(void)` — cuerpo de `funcion principal() -> entero:` (Syquex)
2. `int main(int argc, char** argv)` — wrapper de entry point (C runtime)

Resultado: `error: conflicting types for 'main'`

## Solución (Manual 2 §2)

El Manual 2 §2 define `funcion principal()` como el entry point. La solución:

1. **`emit_declarations.py`**: Renombrar `principal()` a `_principal_impl()` en el C generado
2. **`generator.py`**: Actualizar llamadas a `_principal_impl()` en `_emit_main`
3. **`transpiler.py`**: Renombrar `funcion main()` (del Python `def main():`) a `_main_py()`
