# R182a — ME r182a_wasm_f25_funcional

## Resumen

Criterio Fase 25 ("genera WASM válido") incumplido: `synapse build --target wasm`
generaba WAT estructuralmente inválido — `call` a funciones no definidas sin
`(import ...)`, variables sin `(local ...)` declarado, stack desbalanceado en
llamadas usadas como sentencia, y funciones `-> nulo` con `(result i32)` sin
retorno. `wat2wasm` (wabt 1.0.39, disponible en `C:/emsdk/node/*/`) rechazaba
todo módulo. Adicionalmente, `pipeline.py` solo buscaba wat2wasm en PATH y
imprimía `[INFO] wat2wasm no encontrado`.

Aclaración del levantamiento: los "3 RED del plan" (test_wasm_extended 9/9,
test_wat_generator 16/16, test_spa_counter) ya estaban verdes — el RED real se
confirmócompilando un probe `.syn` con `--target wasm` y validando el `.wat`
con wat2wasm (RED: `error: undefined function variable "$escribir_linea"`).

## Cambios (commit 0c74d80)

- `compilador/wat_generator.py` — cumple Manual 1 §3.2:
  - `_firma_llamada_externa`: toda `LlamadaFuncion` no definida en el AST se
    registra como import `"env"` con firma inferida best-effort de los argumentos
    (determinista: primera aparición fija la firma).
  - `_declarar_locals`: `(local ...)` para cada `DeclaracionVariable` no-param,
    recursivo en `si`/`mientras` (orden de aparición = determinismo).
  - `drop` en llamadas en posición de sentencia (stack balanceado).
  - export automático de `principal`/`main`; `nulo`/`void` sin `(result)`;
    default inalcanzable al final de funciones con result (validación estática
    del implicit return de WASM); imports emitidos ANTES de toda definición
    (wat2wasm: "imports must occur before all non-import definitions"; incluye
    antes de `(memory)`/`(export "memory")`).
- `pipeline.py` — cumple Manual 8 §4.2: la fase F25 `.wat → .wasm` busca
  wat2wasm en PATH y en emsdk (`C:/emsdk/node/*/wat2wasm.CMD|exe`).
