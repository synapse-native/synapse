# reporte R275 — r275_opensyn_e2e_bench

**Estado:** CERRADO (implementación y evidencia local) 2026-11-20
**Micro-entregable:** `r275_opensyn_e2e_bench` (Frente H, Ola H2)
**Manuales citados:** Manual 7 §7.2, §7.3, §8; Manual 9 §5.5

## Qué se corrigió

El ME estaba sólo maquetado: el plan citaba requisitos que no eran los del
plan canónico (`PLAN_MEJORAS_ECOSISTEMA_R270_R284.md:256-283`) y el oráculo
`auditoria/oraculos/oraculo_r275_opensyn_e2e_bench.py` era un placeholder que
imprimía `[OK]` y devolvía RC=0 sin ejecutar nada (`--construir` no construía,
`--mutar` no mutaba, `--e2e` decía "placeholder active").

Ahora:

- `docs/plan_ME_r275_opensyn_e2e_bench.md` se reescribió con bloques MTS
  `requisito:`/`texto:`/`implementacion:`/`oraculo:` reales para M7 §7.2,
  §7.3, §8 y M9 §5.5.
- `tests/integration/test_opensyn_e2e_local.py` (nuevo, opt-in `OPENSYN_E2E=1`)
  levanta `llama-server` real en loopback, ejecuta chat real, mide latencia,
  tokens/s y VRAM, valida código con `synapse check --no-emit`, compila y
  ejecuta una sonda de sandbox (`editar` dentro = ASK, fuera = DENY, `leer`
  dentro = ALLOW) y monitorea las conexiones de `opensyn.exe doctor`.
- `tests/integration/test_opensyn_sin_red.py` (nuevo, siempre ejecutable)
  verifica que todo endpoint HTTP literal de `opensyn/` sea loopback o una
  descarga documentada del instalador, y que no haya telemetría/analytics sin
  descargo.
- El runner `auditoria/oraculos/oraculo_r275_opensyn_e2e_bench.py` ahora
  ejecuta pytest de verdad y devuelve el RC real. Además resuelve la capacidad
  del entorno (`llama-server` + GGUF) y exporta `OPENSYN_E2E=1` él mismo: si
  hay modelo ejecuta la evidencia, y si no lo hay termina `rc=1` con la causa
  concreta en lugar de devolver 0 tras un SKIP (que `contrastar.py` rechaza
  como ausencia de evidencia).
- Las dos entradas del plan que apuntaban directamente al test E2E
  (`oraculo: tests/integration/test_opensyn_e2e_local.py`) ahora apuntan al
  runner. Antes `contrastar` ejecutaba el test sin opt-in, obtenía SKIP y
  fallaba; el PASS que declaraba el reporte original no era reproducible.
- `docs/plan_ME_r275_opensyn_e2e_bench.md` aclara el reparto: el test conserva
  el opt-in (CI sin modelo no finge verde) y el runner es el oráculo.

## Hallazgo

- **H-R275-1 (MEDIO):** el binario nativo S2 (`dist/bin/synapse.exe`) no
  compila `opensyn/permisos.syn`: emite `str_eq(car_sep, ...)` con `car_sep`
  como `int64_t` en `es_ruta_workspace` (comparación de texto indexado). S1
  (`main.py`) sí lo compila. La sonda E2E usa S1 y deja el aviso
  `[R275][WARN]`; el binario nativo sí se usa para `check --no-emit`.
  Resolución asignada: alinear la emisión de `str_eq` para texto indexado en S2
  o cambiar la comparación de `permisos.syn` a `subcadena(...)`; registrar en
  `docs/plan_maestro_deudas.md`.

devuelve verde sin evidencia). Siguiente: r276
(`r276_multiplataforma_release`), corrigiendo antes el ME inventado
