## Problema

Run `45183357177`, job `release_matrix (macos-latest)`:

```
runtime/core/detect_hardware.c:12:10: fatal error: sys/sysinfo.h: No such file or directory
[ME-R2][ERROR] Fallo al compilar runtime desde fuente
[build][ERROR] rc=1
```

`sys/sysinfo.h` y `/proc/*` son de Linux y se usaban sin guarda en
`runtime/core/detect_hardware.c` **y** en `nucleo/detect_hardware.c` (el runtime
legacy también se compila en el bootstrap).

## Cambios

- Include `<sys/sysinfo.h>` solo bajo `__linux__` en ambos archivos.
- `_syn_memoria_libre`: rama Linux intacta (`struct sysinfo`) y rama POSIX
  nueva.
- `nucleo/detect_hardware.c`: perfil con `#elif defined(__linux__)` (sysinfo,
  `/proc/mtrr`, `/proc/iomem`, `nvidia-smi`) y `#else` con `sysconf`.
