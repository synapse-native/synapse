## Reprodu

repro 2026-10-25). El emisor RAII del scope liberaba el parámetro `p: texto`
cedido a un campo de struct — así se armaba `ModeloInfo.ruta` desde un concat,
el scope local emitía `_syn_texto_liberar(p)` tras la cesión, el slab TLS
reciclaba el buffer y el concat siguiente escribía encima: config.toml salía
con `ruta` corrupta (prefijo reciclado + NUL).
