## Problema

| target | error de CI |
|---|---|
| ubuntu-latest, ubuntu-24.04-arm | `tui.c:1863: unknown type name 'DIR'`; `struct dirent` y `struct stat` desconocidos |
| macos-latest (darwin_arm64) | `concurrency.c:901: '_SC_NPROCESSORS_ONLN' undeclared` |

Ninguno se reproducía en Windows: la rama `_WIN32` evita todo el código
afectado, por eso el proyecto compilaba localmente y no en la matriz.

## Cambios

- `runtime/core/tui.c`: incluye `<dirent.h>` y `<sys/stat.h>` en la rama no
  Windows.
- `runtime/core/concurrency.c`: `_XOPEN_SOURCE 700` solo fuera de Darwin; en
  `__APPLE__` incluye `ucontext.h` + `unistd.h` con el perfil completo.

## Limitación declarada

La compilación en Linux/macOS solo se confirma en CI. La hipótesis de este ME
sobre Darwin (`_XOPEN_SOURCE` innecesario) fue **desmentida** por el run
siguiente y corregida en r312: el SDK de macOS aborta si no está definido.
