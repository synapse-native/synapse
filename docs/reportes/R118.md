## DESCRIPCIÓN

Sistema que permite a OpenSyn corregir automáticamente código generado con errores de compilación, utilizando el flag `--check` del CLI de Synapse.

### Componentes implementados:

1. **Archivo de implementación** (`opensyn/validation_loop.syn`):
   - `validar_codigo_con_check()`: Valida código con `synapse check --no-emit`
   - `reconstruir_prompt_con_error()`: Reconstruye prompt con mensaje de error
   - `guardar_feedback()`: Guarda feedback humano en `~/.opensyn/feedback.jsonl`
   - `bucle_validacion()`: Función principal del bucle (máximo 3 intentos)

2. **Estructuras de datos**:
   - `ErrorCompilacion`: Línea, columna, mensaje, archivo
   - `ResultadoValidacion`: Es válido, errores, intentos realizados

3. **Flujo implementado** (M7 §6.3):
   - Intento 1: Generación inicial + validación
   - Intentos 2-3: Reconstrucción de prompt con error + regeneración
   - Fallo definitivo: Mensaje de error + guardado de feedback
