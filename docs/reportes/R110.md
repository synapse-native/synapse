## Entregables

### opensyn/generate_runtime_bindings.py
- Script que genera `lib/runtime_bindings.syq` desde los headers del runtime
- Uso: `python opensyn/generate_runtime_bindings.py [-o output.syq]`
- Recorre 7 headers y genera `externo funcion` para cada función pública

### lib/runtime_bindings.syq
- 91 funciones externas generadas automáticamente desde 7 headers:
  - **math.h** — 9 funciones (potencia, sqrt, sen, cos, tan, round, ceil, floor, log)
  - **texto.h** — 17 funciones (longitud, subcadena, contiene, reemplazar, dividir, etc.)
  - **tiempo.h** — 14 funciones (timestamp, fecha, hora, zona, formato, sleep)
  - **db.h** — 18 funciones (abrir, cerrar, ejecutar, consultar, cursor, etc.)
  - **web.h** — 16 funciones (crear, destruir, registrar_ruta, iniciar, etc.)
  - **json.h** — 7 funciones (parsear, serializar, acceder, etc.)
  - **ffi_marshaling.h** — 10 funciones (texto_a_c_string, entero_a_i64, etc.)

### Bugfix: bindings_generator.py
- Eliminado filtro `nombre.startswith('_')` que bloqueaba todas las funciones `_syn_*`
- Las funciones `_syn_*` son el API público del runtime, no internas
