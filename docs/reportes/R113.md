### Bugfixes del Transpiler (opensyn/transpiler.py)

| Bug | Antes | Después |
|-----|-------|---------|
| Tipo annotations | `funcion nombre(params):` | `funcion nombre(params: entero) -> entero:` |
| For loops | `para i en rango(10):` | `para i = 0 mientras i < 10: ... i = i + 1` |
| Import automático | No generaba imports | `importar std.io` cuando usa `escribir_linea` |
| Nivel superior | Código suelto generaba error | Envuelve en `funcion principal() -> entero:` |
| Preservar indentación | Strippeaba toda indentación | Mantiene indentación original |

### Pipeline Verificado

```
counter.py (Python)
    │
    ├─ [1] opensyn/transpiler.py
    │      -> counter.syn (Syquex válido)
    │
    └─ [2] main.py (compilador S1)
           -> counter.c (C generado)
           -> counter.exe (link falla por SQLite preexistente)
```

**Nota:** El linker falla por `undefined reference to sqlite3_*` — es un issue
preexistente del build system (SQLite no está enlazado), no del transpiler.
