## Entregables

### opensyn/full_pipeline.py
- Orquestador del pipeline end-to-end
- `ejecutar_pipeline(ruta_py)`: ejecuta todo el pipeline y retorna (codigo, syq, exe)
- `transpilar_py_a_syq()`: paso 1 de transpilación
- `compilar_syq_a_exe()`: paso 2 de compilación usando `ejecutar_compilador`
- CLI propio: `python opensyn/full_pipeline.py input.py [-o output.exe]`

### --pipeline flag en CLI
- **Uso:** `python cli.py --pipeline input.py [-o output.exe]`
- Ejecuta automáticamente: .py → .syq → .c → .exe
- Soporta `--release` y `--debug`
- Limpia el .syq temporal al finalizar

### Bugfixes
- **Envolver código de nivel superior:** transpiler ahora detecta código suelto
  (fuera de funciones) y lo envuelve automáticamente en `funcion principal() -> entero:`
- **Unicode →:** Eliminado de todos los mensajes (compatibilidad Windows cp1252)

## Flujo del Pipeline

```
input.py
  │
  ├─ [1] opensyn/transpiler.py
  │      .py → .syq (mapeo tipos, keywords, builtins)
  │      Envuelve código de nivel superior en funcion principal()
  │
  └─ [2] pipeline.ejecutar_compilador()
         .syq → .syn (parser + semántico)
         .syn → .c (code generator)
         .c → .exe (GCC)
```
