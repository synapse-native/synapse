## TAREA

Implementar el sistema de inyección de contexto estático para OpenSyn según Manual 7 §2.3.

## MANUAL REFERENCIADO

Manual 7 §2.3: "OpenSyn inyecta un bloque de 'Reglas de Sintaxis' en el System Prompt de cada consulta. Este bloque contiene la gramática esencial, el modelo de memoria y ejemplos de Synapse/Syquex."

## DESCRIPCIÓN

Sistema que permite a OpenSyn conocer Synapse y Syquex de forma nativa mediante la inyección de un bloque de reglas de sintaxis en el System Prompt de cada consulta RAG.

### Componentes implementados:

1. **Archivo de configuración** (`opensyn/reglas_synapse.toml`):
   - Reglas de sintaxis de Synapse (funciones, variables, condicional, bucle, retorno, concurrencia, canales, tensores)
   - Reglas de sintaxis de Syquex (funciones, estructuras, métodos, constructores, errores, concurrencia, canales, módulos)
   - Ejemplos de código
   - Configurable y actualizable por el usuario

2. **Parser TOML** (`nucleo/synapse_rag.c`):
   - `rag_parsear_toml_simple()`: Parsea archivos TOML simples
   - Soporte para secciones `[config]`, `[synapse]`, `[syquex]`, `[ejemplos]`

3. **API de configuración** (`nucleo/synapse_rag.h`):
   - `RagContextoEstatico`: Estructura para reglas de contexto
   - `RagConfiguracionEstatica`: Estructura de configuración
   - `rag_configuracion_inicializar()`: Valores por defecto
   - `rag_configuracion_cargar()`: Carga desde archivo TOML
   - `rag_configuracion_liberar()`: Libera memoria

4. **Construcción de prompt** (`nucleo/synapse_rag.c`):
   - `rag_construir_bloque_estatico()`: Genera bloque [SYSTEM] con reglas
   - `synapse_rag_construir_prompt_con_contexto_estatico()`: Integra contexto estático + dinámico
