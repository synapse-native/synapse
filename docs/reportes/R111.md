## Entregables

### scripts/githooks/pre-commit (actualizado)
- Nuevo paso: **"Verificando cambios en headers del runtime"**
- Detecta archivos `runtime/core/*.h` en el staging area
- Si hay cambios, ejecuta `opensyn/generate_runtime_bindings.py` automáticamente
- Añade `lib/runtime_bindings.syq` regenerado al commit
- Si falla la regeneración, advierte pero no bloquea el commit (no-crítico)

### Flujo del hook

```
1. Limpiar artefactos de build
2. ✅ Verificar cambios en headers del runtime  ← NUEVO
   ├─ Si headers cambiaron → regenerar bindings → git add
   └─ Si no cambiaron → skip
3. Verificar alineación con manuales
4. Gate de lectura previa
5. Verificar ast_nodos.h sincronizado
```

### Tests
- `tests/test_bindings_hook.py` — 8 tests
  - Detección de cambios en headers
  - Regeneración funciona correctamente
  - Idempotencia (regenerar 2 veces = mismo resultado)
  - Formato válido de todas las líneas `externo`
  - CLI del script generador

## Uso

```bash
# La regeneración es automática — no hay que hacer nada manual
git add runtime/core/math.h
git commit -m "feat: nueva función matemática"
# → El hook regenera lib/runtime_bindings.syq automáticamente

# Regenerar manualmente (opcional)
python opensyn/generate_runtime_bindings.py
```
