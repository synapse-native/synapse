# R182c — ME r182c_canal_vivir (pruebas de operación como usuario real)

## Resumen

Hallazgo H-R182c-1 de la batería de pruebas de operación como usuario real:
el programa canónico M3 §8.1 de canales en `.syq` compilaba rc=0 pero al
ejecutar imprimía un entero basura (1933533161441) y segfaulteaba (rc=139).

```syq
funcion principal():
    let c = Canal<entero>(10)
    lanzar productor(c)
    escuchar c:
        let v = c ->
        escribir_linea(entero_a_texto(v + 1))
```

## Causa raíz (commit 057d072)

El cleanup final de la función contenedora
(`compilador/generator/emit_declarations.py`) emitía `canal_destruir(var)`
INcondicional para todo canal registrado en `_canal_vars_concurrencia`,
aunque el canal hubiera sido cedido a una fibra:

- `escuchar c:` → `fibra_crear(listener, c)` (M5 §2.6)
- `lanzar productor(c)` → wrapper `_wrap_N` con `c` en el struct de args

El listener vivía con un puntero a canal ya destruido → use-after-free,
entero basura impreso y segfault.

## Cambios

- `compilador/generator/context.py`: nuevo set `_canal_vars_cedidas` —
  canales cuya propiedad pasa a la fibra (comentarios con anclas

- `compilador/generator/emit_declarations.py`:
