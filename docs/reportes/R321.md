# Reporte R321 — ME r321_weak_darwin

**Commit:** `18c150a`
**Fecha:** 2026-11-23
**Fase:** Release v8.1.0-industrial — dejar verdes los workflows

## Problema

Run `45217779214`, job `137843493888` (macos-latest), después de r320:

```
duplicate symbol '_escribir_linea' in:
    .../synapse_unity.c.o
    /Users/runner/.synapse/cache/runtime_obj/io.o
duplicate symbol '_str_eq' in:
    .../synapse_unity.c.o
    /Users/runner/.synapse/cache/runtime_obj/sistema.o
ld: 23 duplicate symbols
[ME-R2][ERROR] No se genero el ejecutable: synapse_bootstrap.exe
```

El C emitido redefine helpers que ya existen en el runtime. GNU ld lo toleraba
con `--allow-multiple-definition` (gana la primera definición); al retirar el
flag en darwin (r320) el enlace destapó el motivo real.

## Cambios

- `compilador/generator/emit_declarations.py`: `weak` vale
  `__attribute__((weak))` cuando `sys.platform == "darwin"` y vacío en el resto;
  se intercala en la firma de `visitar_funcion`.
- `nucleo/generador/funciones.syn`: `_weak_attr` (vacío, o el atributo bajo
  `#ifdef __APPLE__`) en el `snprintf` de la firma, para que también S1→S2→S3
  emitan igual.
