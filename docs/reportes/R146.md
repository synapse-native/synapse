# R146 — Prueba interactiva real en VS Code con instalación completa

**Fecha:** 2026-09-10 · **Fase:** 30-b HARDENING · **Commit:** `df8ff5f` (sobre `dd0d90b`/`4a7e77d`/`bdb615c`)

## Objetivo

Prueba interactiva real del producto: instalación completa (instalador 8.1.0),
extensión VS Code operativa, y el flujo IA (chat + comando `aiExplain`)
ejerciendo los fixes de R145b (parser SSE + stop sequences) contra llama-server
real en `:11434` (deepseek-coder-1.3b).

## Bloqueantes encontrados y resueltos

### 1. `synapse/aiExplain` no estaba implementado en el LSP (Manual 8 §2.3)

El comando de paleta `synapse.aiExplain` de la extensión invoca el método LSP
`synapse/aiExplain`; el dispatch de `nucleo/lsp_v3.syn` respondía `-32601`
(método no encontrado) y el comando quedaba colgado. Implementado conectado al
backend real: resuelve el modelo (config `cwd` → `HOME\.opensyn` → install dir,
Manual 9 §5) y consulta con `_syn_ollama_consultar` (mismo cliente corregido en
R145b). El módulo quedó en 1256 L > 1200 → registrado en
`docs/decisiones/MODULOS_D9.md` (regla 13; el verificador lo exigía).

### 2. H-R146-1: contexto del agente NO determinista

El oráculo banner pasó de GREEN a fallar de forma repetible. Diagnóstico:
`temperature:0` hace el output determinista, pero **la entrada variaba**: el
listado de la raíz inyectado al modelo (contexto estático y `TOOL listar`)
incluía los artefactos que cada build S1 genera en la raíz (`_principal.c`,
`_texto.c`, `*.o`, `synapse_bootstrap.exe`, `_probe_*` de sesiones previas).
El modelo 1.3B, además, **repetía el listado multilinea en bucle** hasta agotar
`max_tokens` sin nombrar ningún directorio aceptado.

Fix (`opensyn/principal.syn`):
- `filtrar_listado()`: excluye artefactos por convención del repo (prefijo `_`,
  `.c.o`/`.o`/`.syn.json`/`.exe`) y devuelve UNA línea separada por `", "`.
- Aplicado a `TOOL listar` y al contexto estático (`construir_contexto`).
- Acotado a 2400 chars con aviso de truncado (`TOOL listar <subdirectorio>`).

Resultado: respuestas deterministas con contenido real (`AGENTS.md`,
`docs/`, `auditoria/`, `examples/`…), sin bucles.

### 3. Prompt del oráculo con número literal

`"nombra 3 reales"` → el modelo responde literalmente `3` (determinista con
temp 0). Reformulado a pregunta natural, documentado en el docstring del test
(dentro de la autorización R145 del Arquitecto sobre este oráculo).

## Lecciones (registradas en MEMORIA)

1. Reconstruir instalador + reinstalar + verificar sha256 inmediatamente tras
   corregir binarios: la prueba interactiva debe ejercer el binario validado.
2. Prompts de oráculos sin números literales (los modelos pequeños los
   copian como respuesta).
3. Los artefactos que el propio build genera en la raíz contaminan cualquier
   listado inyectado a un agente — filtrar por convención, no limpiar a mano.
