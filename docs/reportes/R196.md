## R1 — `test_string_utils.py::TestContiene::test_contiene_subcadena_vacia`

**Causa raíz (H-R196-1):** el contrato `requiere: longitud(subcadena) > 0` en
`std/texto.syn` (contiene e indice_de), añadido por el barrido de cláusulas de
r192 **sin mandato del manual** — M8 §1.7.3 declara los bindings
`externo funcion contiene(texto: texto, subcadena: texto) -> entero` SIN
precondición ("Verificación de subcadena"; §1.7.4: "Búsqueda de primera
ocurrencia"). El runtime C ya maneja la subcadena vacía, pero el enforcement
de contratos (M2 §5.1, r194) abortaba ANTES de ejecutar (rc=127, "Fallo en
contrato: requiere") → stdout vacío → el test E2E (compilar+ejecutar) fallaba.

**Decisión del Arquitecto (sesión 2026-10-23, ratificada):** "Corregir contrato
al manual" — se retira el `requiere` de contiene e indice_de; el `garantiza`
booleano se mantiene (M2 §12/§5.1 intactos).

**Fix:** `std/texto.syn` (4 sitios: contiene×2, indice_de×2 — H-R196-2: las 12
funciones del std están **duplicadas** en dos bloques completos; el emisor
deduplica a 1 def C por función y la última copia gana, probado con lector del
C generado). Anclas `// cumple Manual 2 §5.1 (ME r196)` + `Manual 8 §1.7.3`.

**Verificación:** probe E2E real (`contiene("hola","")` → 1,
`indice_de("hola","")` → 0, rc=0); `pytest tests/integration/test_string_utils.py`
→ **13 passed**; oráculo r196 4/4.
