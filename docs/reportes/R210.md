## Lecciones

- El parser S1 no reconoce `continuar`; usar condiciones anidadas o invertidas.
- La indexación de `Lista<texto>` puede inferir `int`; encapsularla en una
  función con retorno `texto` evita comparaciones texto/int.
- Un archivo puede tener varios nodos; el BFS debe recorrer todos los nodos del
  archivo y deduplicar por archivo, no por nodo.
- El gate de lectura usa `mapa_manuales.md` (`opensyn/*` -> Manual 7), no solo
  `mapa_alineacion.md`; registrar ambas citas antes del commit.
