# Depuración en Synapse

Este capítulo cubre las herramientas y técnicas de depuración disponibles en Synapse. Aprenderás a usar el depurador integrado, macros de depuración y herramientas externas para encontrar y corregir errores.

Una buena estrategia de depuración es esencial para desarrollar software de calidad.
