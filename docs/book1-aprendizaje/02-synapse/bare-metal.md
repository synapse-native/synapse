# Bare Metal con Synapse

Este capítulo cubre el uso de Synapse en entornos de hardware bare metal, sin sistema operativo. Aprenderás sobre `no_std`, allocación de memoria manual y programación de bajo nivel.

Synapse es ideal para sistemas embebidos y firmware gracias a su control fino sobre los recursos del sistema.
