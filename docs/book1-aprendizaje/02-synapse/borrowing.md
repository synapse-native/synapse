# Borrowing en Synapse

Este capítulo cubre el préstamo de referencias (borrowing) en Synapse, un mecanismo que permite usar valores sin tomar ownership. Aprenderás sobre referencias inmutables y mutables, y las reglas que previenen data races.

Borrowing es esencial para escribir código eficiente que comparta datos de forma segura.
