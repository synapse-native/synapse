# Cadenas en Synapse

Este capítulo explora el manejo de cadenas de texto en Synapse. Aprenderás sobre `Cadena` (String), `&str`, y las operaciones disponibles para manipular texto de forma segura y eficiente.

Las cadenas en Synapse están diseñadas para ser seguras contra errores de codificación y encoding.
