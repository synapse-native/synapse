# Lifetimes en Synapse

Este capítulo explora los lifetimes (tiempo de vida), el sistema que garantiza que las referencias siempre sean válidas. Aprenderás a anotar lifetimes y entender cuándo el compilador los necesita.

Los lifetimes son una herramienta avanzada pero necesaria para escribir código seguro con referencias complejas.
