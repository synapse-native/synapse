# Fibras en Synapse

Este capítulo presenta las fibras (fibers), el modelo de concurrencia ligera de Synapse. Aprenderás a crear, schedulear y comunicar fibras para construir aplicaciones concurrentes de alto rendimiento.

Las fibras son la unidad básica de concurrencia en Synapse, ofreciendo un balance entre simplicidad y control.
