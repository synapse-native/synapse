# Ownership en Synapse

Este capítulo explica el sistema de ownership (propiedad), uno de los conceptos más distintivos de Synapse. Aprenderás cómo Synapse gestiona la memoria sin recolector de basura, garantizando seguridad en tiempo de compilación.

El ownership es la base de la seguridad de memoria en Synapse, eliminando errores comunes como use-after-free, double-free y data races.
