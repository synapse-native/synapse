# Optimización en Synapse

Este capítulo explora técnicas de optimización de rendimiento en Synapse. Aprenderás sobre inlining, monomorfización, optimización de estructuras de datos y cómo escribir código que aproveche al máximo el compilador.

Synapse está diseñado para producir código de alto rendimiento, y comprender las técnicas de optimización te ayudará a escribir programas más eficientes.
