# Expresión `elegir` en Synapse

Este capítulo se enfoca en la expresión `elegir` (equivalente a `match` en otros lenguajes), una herramienta poderosa para el pattern matching y la descomposición de datos.

`elegir` permite escribir código más expresivo y seguro, aprovechando el sistema de tipos para cubrir todos los casos posibles de forma exhaustiva.
