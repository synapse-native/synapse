# Control de Flujo en Synapse

Este capítulo cubre las constructuras de control de flujo en Synapse: condicionales, bucles y patrones de iteración. Aprenderás a dirigir la ejecución de tu programa de manera segura y expresiva.

Synapse ofrece sintaxis moderna para el control de flujo, con integración profunda del sistema de tipos para garantizar la corrección en tiempo de compilación.
