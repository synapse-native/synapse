# Variables en Synapse

Este capítulo cubre la declaración, tipado y uso de variables en Synapse. Aprenderás sobre el sistema de tipos estático, la inferencia de tipos y las reglas de mutabilidad que garantizan la seguridad en tiempo de compilación.

El dominio de las variables es fundamental para escribir código correcto y eficiente en Synapse, ya que el compilador verifica automáticamente las reglas de propiedad y préstamo.
