# Estructura de un Programa en Synapse

Este capítulo describe la estructura típica de un programa en Synapse, incluyendo módulos, archivos, el punto de entrada y la organización del código.

Comprender la estructura correcta es esencial para construir proyectos escalables y mantenibles en Synapse.
