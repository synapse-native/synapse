# Arreglos en Synapse

Este capítulo cubre los arreglos (arrays) y colecciones en Synapse. Aprenderás sobre arreglos de tamaño fijo, vectores dinámicos, slices y las operaciones disponibles para trabajar con colecciones de datos.

Las colecciones son fundamentales para organizar y procesar datos en cualquier programa.
