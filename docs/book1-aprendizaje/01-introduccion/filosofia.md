# Filosofía del Ecosistema Synapse

Este capítulo explora los principios de diseño que guían la creación de Synapse, Syquex y OpenSyn. Comprenderás por qué el ecosistema adopta un enfoque único para la programación concurrente, la seguridad de tipos y la experiencia de desarrollo.

El objetivo es proporcionar una base sólida para tomar decisiones informadas al trabajar con estas herramientas, y entender las razones detrás de cada elección de diseño.
