# Tareas en Syquex

Este capítulo explora las tareas (tasks) como unidad de trabajo concurrente en Syquex. Aprenderás a crear, schedulear y comunicar tareas para construir aplicaciones paralelas.

Las tareas permiten ejecutar múltiples operaciones de forma concurrente sin bloquear el hilo principal.
