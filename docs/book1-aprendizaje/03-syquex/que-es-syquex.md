# ¿Qué es Syquex?

Este capítulo presenta Syquex, un lenguaje de programación de alto nivel diseñado para productividad y simplicidad. Aprenderás su propósito, filosofía de diseño y casos de uso ideales.

Syquex combina la facilidad de uso de lenguajes como Python con un sistema de tipos potente y soporte nativo para concurrencia, haciéndolo ideal para aplicaciones de servicio y scripting avanzado.
