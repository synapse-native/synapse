# Casos de Uso de Syquex

Este capítulo explora los escenarios donde Syquex brilla: servicios web, scripting, procesamiento de datos, automatización y más. Aprenderás a identificar cuándo Syquex es la mejor opción.

Syquex está diseñado para ser versátil, con especial énfasis en la concurrencia y el manejo eficiente de E/S.
