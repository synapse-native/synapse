# Instalación de Syquex

Este capítulo guía el proceso de instalación de Syquex en diferentes sistemas operativos. Aprenderás a configurar tu entorno de desarrollo y verificar que todo funciona correctamente.

Una instalación correcta es el primer paso para comenzar a programar en Syquex.
